把语镜放到手机 / 平板上

同一张 Wi-Fi 下，手机浏览器打开下面的地址就能用。翻译、对照、语法、历史都在电脑上跑，手机只是屏幕。

正在检查连接状态…
  1. 手机连同一个 Wi-Fi电脑和手机要连同一个路由器。校园网、酒店网如果开了“设备隔离”，两台设备可能互相看不到。
  2. 在手机浏览器里输入地址一台设备输入一次就够，之后可以直接从历史记录或主屏幕打开。
  3. 添加到主屏幕iPhone：Safari 分享 → 添加到主屏幕。安卓：Chrome 右上角菜单 → 添加到主屏幕。
局域网模式没有密码：同一个 Wi-Fi 里的人都能打开语镜，也会看到你的翻译历史。只在家里或可信网络用，公共 Wi-Fi 用完就关掉。
手机打不开？多半是 Windows 防火墙

第一次从手机访问时，Windows 可能拦住了端口。任选一种：

  1. 双击语镜文件夹里的 放行手机访问.vbs，在弹出的管理员确认里点“是”。它会为语镜的端口加一条规则。
  2. 启动器第一次运行时也会主动问你要不要放行；当时点了“否”的话，用上一条补上。
  3. 或打开“Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙”，手动放行 Python 的入站连接。

如果电脑连着公共 Wi-Fi，Windows 默认会拦掉所有入站连接；放行后能用，但用完最好关掉手机版。地址里的 IP 变了，通常是换了 Wi-Fi 或路由器重新分配，重新打开一次手机版就好。
